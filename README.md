# Remotion Best Practices

> A Claude Code skill providing comprehensive Remotion framework reference — video creation in React

## What This Does

A knowledge base of 37+ rule files covering every aspect of Remotion development. Automatically loaded when working with Remotion code, giving Claude deep domain knowledge about video creation in React.

Topics covered include:
- 3D content (Three.js, React Three Fiber)
- Animations, transitions, and timing
- Audio handling and visualization
- Captions, subtitles, and voiceover
- Charts and data visualization
- Assets (images, videos, fonts, GIFs)
- FFmpeg integration
- And 25+ more

## Installation

```bash
git clone https://github.com/bohdan-aif/cc-skill-remotion-best-practices.git ~/.claude/skills/remotion-best-practices
```

Automatically activated when working with Remotion projects.
